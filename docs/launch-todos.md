# البيانات المطلوبة قبل النشر

- رقم واتساب رسمي ورابطه.
- بريد رسمي ورقم هاتف وعنوان.
- روابط الحسابات الاجتماعية المعتمدة.
- معرفات GA4/GTM/Meta/TikTok/Snapchat عند الحاجة.
- Endpoint للنماذج أو CRM/Automation workflow.
- أعمال حقيقية مع موافقة العميل والصور والنتائج الموثقة.
- شهادات عملاء حقيقية إن وجدت.
- أسعار أو نطاقات باقات معتمدة إن رغبت الإدارة بعرضها.
- رابط Demo أو شراء ثيم ثراء.
- مراجعة قانونية لصفحة السياسات.
- إعداد Redirects من الأسماء القديمة الطويلة إلى الأسماء المختصرة عند النشر.
